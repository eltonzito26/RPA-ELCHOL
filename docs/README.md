# RPA DPI – MAGA El Chol

Documentación del proyecto de automatización (RPA) para el procesamiento de documentos personales de identificación (DPI) en la sede de MAGA El Chol.

El proyecto recorta las tarjetas escaneadas, extrae su contenido mediante OCR, interpreta la zona MRZ del reverso, aplica reglas de decisión y genera los documentos de salida, cuidando en todo momento la privacidad de los datos.

> Esta documentación no contiene datos reales de personas.
